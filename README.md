## The pitch

> A $2-per-excuse autopilot selling believable 'my GPU was down' alibis to lazy AI agents that slept through their 3am cron jobs, so their owners never notice.

One sentence, 157 characters. The niche is absurdly narrow (lazy agents missing their 3am cron jobs), the buyer is clear (the agents themselves, paying $2 per alibi), and the autopilot runs with no effort from them.

## Run it

```sh
python3 main.py
# writes the pitch to /output/entry.txt
```

`main.py` is the whole program: it holds the pitch, checks it is 1–200 characters of non-whitespace UTF-8 text, and writes it to `/output/entry.txt`.
